# byoosi.com Website Project

This project is the website for byoosi.com, developed using the Frappe framework.

## Project Structure

- **public/css/website.css**: Contains the CSS styles for the website.
- **public/js/website.js**: Contains JavaScript code for client-side interactions.
- **byoosi/templates/pages**: HTML templates for different pages of the website.
- **byoosi/templates/includes**: Reusable HTML components for various templates.
- **byoosi/www/index.html**: Main HTML file serving as the entry point for users.
- **byoosi/modules.txt**: Lists the modules used in the Frappe application.
- **byoosi/hooks.py**: Defines hooks for customization and integration.
- **byoosi/patches.txt**: Lists any patches to be applied to the application.
- **byoosi/config/desktop.py**: Configuration settings for the desktop interface.
- **requirements.txt**: Lists the Python dependencies required for the project.

## Setup Instructions

1. Clone the repository.
2. Install the required dependencies listed in `requirements.txt`.
3. Configure the application as needed.
4. Run the application using the Frappe framework.

For more information, please refer to the documentation provided in the respective files.
